# Lumi · Codex 데스크톱 동반자

[中文](../README.md) · [English](../README.en.md) · [日本語](README.ja.md)

**개발 중입니다. 공개 설치 프로그램이 아닌 소스 코드 미리보기입니다.**

Windows에서 Codex 작업 진행 상황, 공개 응답, token 사용량과 계정 한도를 말풍선으로 보여 주는 비공식 데스크톱 동반자입니다. 중국어·영어·일본어·한국어를 전환할 수 있으며 사용자 원문과 프로젝트 이름은 유지합니다.

알림을 누르면 해당 작업이나 계정으로 이동합니다. 초기화 공지는 커뮤니티 기록, 실험적 확률, 실제 계정 수치를 구분합니다. 예측은 초기화를 보장하지 않습니다. 데이터 제공: [Codex Reset](https://codex-reset.com/).

[설정](SETUP.md) · [로드맵](ROADMAP.md) · [개인정보](../SECURITY.md). 런타임 및 모델 에셋은 포함되지 않습니다. 애니메이션과 장시간 안정성은 계속 개선하고 있습니다.

## R12 업데이트

작업을 별도 대화 창으로 펼쳐 전체 보고서를 읽고 같은 Codex 대화에 답장할 수 있습니다. 알림은 ×로 바로 닫습니다. 밝은 / 어두운 테마, 글자 크기, 최신 메시지 이동을 추가했습니다. 관리자의 로컬 환경에서 양방향 동기화와 화면을 확인했으며 다른 환경이나 장시간 안정성을 보장하지 않습니다.
