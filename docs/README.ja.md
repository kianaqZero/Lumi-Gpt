# Lumi · Codex デスクトップコンパニオン

[中文](../README.md) · [English](../README.en.md) · [한국어](README.ko.md)

**開発中です。公開インストーラーではなく、ソースコードのプレビューです。**

Windows デスクトップで Codex のタスク進捗、公開された返信、token 使用量、アカウントの使用枠を吹き出しに表示する非公式コンパニオンです。中国語・英語・日本語・韓国語を切り替えられます。ユーザーの文章やプロジェクト名は翻訳しません。

通知から対応するタスクやアカウントへ移動できます。リセット告知はコミュニティ記録、実験的な確率、実際のアカウント情報を区別します。確率はリセットの保証ではありません。データ提供：[Codex Reset](https://codex-reset.com/)。

[セットアップ](SETUP.md) · [ロードマップ](ROADMAP.md) · [プライバシー](../SECURITY.md)。ランタイムとモデル素材は同梱していません。アニメーションと長時間動作は引き続き改善中です。
