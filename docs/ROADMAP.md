# 路线图 / Roadmap

本页描述开发方向，不承诺发布日期。可用行为与未验收项分开记录。

- 已实现候选：额度与任务气泡、通知跳转和已读移除、token 简写/精确提示、卡片确认界面、账号页异步检测与恢复保护。
- R10 / R10.1：Codex Reset 概率/置信度/更新时间/时间线、社区记录与账号实测分区、中文/英文/日文/韩文切换，采用四个直接按钮。
- 待实际使用：不同系统下截图/托盘恢复、全屏软件避让、长时间隐藏与运行、退出异常现场收集。
- 待专项验收：真实切号退出竞争及恢复，真实重置卡条件/消费/失败反馈。隔离模拟通过不等于真实操作通过。
- 待改善：翻译全面校对、公告外部原文的语言说明、状态识别对更多 Codex 版本的兼容性。
- 待恢复制作：全身 Live2D 动作幅度、睡眠、眨眼与过渡；功能优化期间暂缓新美术制作。
- 公开发行前：整理角色/模型与第三方分发权利，完成可复现构建、干净环境安装、签名/更新与回退说明。
- R11.2 / R12：独立任务聊天、同一 Codex 聊天回复、通知直接关闭、深浅色与阅读工具已实现，维护者本机同步和外观试用已确认。继续覆盖更多 Codex 版本及断线 / 长时间运行情况。

反馈请优先提供稳定复现步骤；不要提交真实凭据或私人聊天记录。
